# termoscor-media

Materiale publice pentru postările Termoscor.ro pe Facebook, Instagram și TikTok.
Fișierele de aici sunt doar imagini și video-uri care se publică oricum pe rețele;
Metricool le preia prin link direct.

Structură: un folder pe lună (`2026-10/`, `2026-11/` ...), fișiere cu sufix de versiune (`_v1`, `_v2`).
